# GiWiFi 校园网自动登录工具

## 项目信息
- **用途：** 校园网每天凌晨 3 点自动断线，本工具自动检测并重新登录
- **登录地址：** `http://172.27.253.230/gportal/web/login?wlanacname=SDZYY&wlanuserip=172.30.8.159`
- **技术栈：** Python 3.13.5 + PySide6 + requests + psutil
- **打包工具：** PyInstaller → `dist/GiWiFi.exe`
- **当前版本：** v1.2.0

## 功能特性

### 核心功能
- ✅ 系统托盘常驻，自动检测网络状态
- ✅ 断线自动重连
- ✅ 开机自启动
- ✅ 在线时长显示
- ✅ 单实例检测

### v1.0.2 新增功能
- ✅ **Windows 通知** - 登录/登出/断线时弹出系统通知（可在设置中关闭）
- ✅ **设置面板** - 点击标题栏右侧 ⚙ 齿轮图标打开
- ✅ **深色模式** - 完整的暗色主题支持，可在设置中切换
- ✅ **实时网速显示** - 每 2 秒检测一次，显示上传/下载速度
- ✅ **开机静默模式** - 启动后自动最小化到托盘，不显示主窗口
- ✅ **日志查看器** - 右键托盘菜单可查看、刷新、清空日志

## 文件说明
| 文件 | 功能 |
|------|------|
| `main.py` | 主程序入口，单实例检测，静默启动逻辑 |
| `tray_app.py` | PySide6 GUI 界面 + 系统托盘 + 所有功能实现 |
| `login_worker.py` | HTTP 登录请求逻辑（含多种参数变体自动尝试） |
| `network_checker.py` | 后台线程每 30 秒检测网络连通性 |
| `config.py` | 账号密码配置管理（base64 编码存储） |
| `autostart.py` | Windows 注册表开机自启动 |
| `logger.py` | 日志模块 |
| `requirements.txt` | 依赖清单：PySide6, requests, pycryptodome, psutil |
| `dist/GiWiFi.exe` | 打包好的可执行文件（约 50MB） |

## 使用方法

### 基本使用
1. 双击 `dist/GiWiFi.exe` 运行
2. 输入校园网账号密码，点击"保存配置"
3. 勾选"开机自启动"可实现开机自动运行
4. 关闭窗口会最小化到系统托盘，双击图标恢复

### 设置功能
点击标题栏右侧 ⚙ 齿轮图标，可配置：
- **启用 Windows 通知** - 登录/登出/断线时弹出系统通知（默认关闭）
- **开机静默模式** - 启动后自动最小化到托盘（默认关闭）
- **深色模式** - 切换深色主题（默认关闭）

### 其他功能
- **查看日志** - 右键托盘图标 → "查看日志"
- **手动登录/下线** - 右键托盘图标或点击主界面按钮
- **网速显示** - 主界面和托盘 tooltip 显示实时网速

## 重新打包
```bash
pip install -r requirements.txt
pyinstaller --onefile --windowed --name GiWiFi main.py
```
