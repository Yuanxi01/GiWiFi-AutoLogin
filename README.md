# GiWiFi 校园网自动登录工具

## 项目信息
- **用途：** 校园网每天凌晨 3 点自动断线，本工具自动检测并重新登录
- **登录地址：** `http://172.27.253.230/gportal/web/login?wlanacname=SDZYY&wlanuserip=172.30.8.159`
- **技术栈：** Python 3.13.5 + PySide6 + requests + psutil
- **打包工具：** PyInstaller → `dist/GiWiFi.exe`
- **当前版本：** v1.4.24

## 功能特性

### 核心功能
- ✅ 系统托盘常驻，自动检测网络状态
- ✅ 断线自动重连（登录请求在后台线程，界面不卡）
- ✅ 开机自启动
- ✅ 在线时长显示
- ✅ 单实例检测

### 主要特性（v1.4.24）
- ✅ **多账户管理** — 账号输入框右侧小箭头，点开就是已保存的账户列表，点一下自动填好对应的密码；「保存配置」会自动把当前账号入库，「删除」可移除
- ✅ **密码可见性切换** — 密码框右侧小眼睛，点一下看明文，再点回密文
- ✅ **密码本地加密** — 从 base64 升级为 Windows DPAPI 加密（绑定当前 Windows 用户 + 本机），配置文件被拷到别的电脑上也解不开；AES-256-GCM 兜底，旧配置自动迁移
- ✅ **「极光」主题** — 基于 Catppuccin（Latte / Mocha）配色，薰衣草底 + 蓝紫渐变主按钮 + 柔光晕，支持白天 / 黑夜切换
- ✅ **「蓝白创新」主题（默认）** — 蓝白为底、Material 质感的按钮：渐变填充 + 顶沿高光 + 投影 + 周期性扫光（微光/流光观感）、
  点击波纹、悬浮/按下位移动画；卡片带绕圈旋转的流光描边；开关为实心轨道
- ✅ **设置面板重排** — 分组成卡片，标签统一左对齐、开关统一右对齐、选择器同宽，行高一致
- ✅ **动态效果**：
  - 极光光晕缓慢漂移呼吸（20fps，仅极光主题；窗口收进托盘时自动停画，不占 CPU）
  - 状态圆点在线时常亮呼吸，刚连上的一瞬间扩散一圈涟漪
  - 按钮点击水波纹，从鼠标位置向外扩散后淡出
  - 窗口关闭 / 最小化时 180ms 淡出收进托盘（启动时淡入）

  重启前先放掉单实例互斥锁（否则新进程会被"已在运行"挡回去），再用 `QProcess.startDetached` 拉起新进程
- 修复：**点「立即重启」没反应** —— 三个原因一起修：① `QProcess.startDetached` 返回的是
  `(bool, pid)` 元组，原来没判返回值；② 点重启时套着「设置」+「重启提示」两层模态对话框，
  `QApplication.quit()` 掀不掉嵌套事件循环，改成拉起新进程后直接 `os._exit(0)`；
  ③ 加 `subprocess` + `DETACHED_PROCESS` 退路，并在 `giwifi.log` 里记录拉起命令
- 修复：**重启后主题没变** —— `_on_family_changed` 保存的是设置对话框里的 config 副本，
  而 `restart_app()` 里又 `save_config(主窗口.config)`，把刚存的主题家族覆盖回旧值；
  现在重启前先把对话框当前设置写回主窗口并落盘（主题以本次切换的家族为准）
- 修复：**重启时旧窗口卡成白/黑方块** —— 退出前先 `hide()` 掉所有顶层窗口和托盘图标，
  再 `os._exit`，不再让 DWM 挂着最后一帧
- 修复：**重启出的新进程启动即崩** —— `create_icon()` 兜底分支写成了 `return QIcon`
  （返回类对象而非实例），一旦资源读不到就抛 `setWindowIcon called with wrong argument types`；
  同时拉起子进程时清掉 PyInstaller 的 `_MEI*` / `_PYI*` 解包目录变量，避免子进程复用父进程
  即将失效的临时目录（这才是"资源读不到"的诱因）
- 修复：**点「立即重启」彻底没反应** —— 真正原因是 `SettingsDialog._on_family_changed` 里写成了
  `self.restart_app()`，但 `restart_app` 在 MainWindow 上，设置对话框没有这个方法 →
  AttributeError 被 Qt 吞掉（窗口程序没有 stderr），表现就是"点了毫无反应"。改为向父窗口委托，
  并新增全局 `sys.excepthook` 把未捕获异常写进 `giwifi.log`，这类问题以后一眼可见
- 修复：**重启拉不起新进程** —— 改成三路兜底（subprocess+DETACHED_PROCESS / ShellExecute /
  QProcess.startDetached），每路成败都写日志；新进程带 `--restarted` 参数，即使旧进程还没退干净
  也不会被单实例锁挡回去；同时修正 `CreateMutexW` 未声明 `restype` 导致 64 位下句柄被截断、
  `CloseHandle` 失败锁一直挂着的问题
- 新增：**设置面板弹出动效** —— 从下方 14px 上滑 + 淡入（170~200ms）；日志窗口同样适用
- 新增：**齿轮按钮旋转** —— 悬浮转 90°、点击再转半圈（OutBack）；**昼夜切换按钮**切换时图标转 180°
- 修复：**主题切换提示框没有阴影** —— 之前是平贴在背景上的，现已和设置/日志对话框统一
  （QGraphicsDropShadowEffect，blur 25 / 下沉 8px / 80 alpha）
- 新增：**设置里加「运行日志」入口** —— 一行「运行日志 + 查看」按钮，直接打开日志窗口
- 修复：**深色模式下设置面板配色错乱** —— 分组卡与行标签的颜色是在创建对话框时写死的，
  切到黑夜后不会跟着刷新，于是出现「深色底 + 浅色面板 + 深色文字」。现在统一由
  `_apply_settings_colors()` 在构建和 `refresh_theme()` 时重刷；分组 QSS 里也补了 `QLabel` 颜色规则
  （否则子标签会退回系统浅色 palette 变成黑字）
- 优化：深色下分段选择器的选中块改为「比轨道亮两档」的面色，之前轨道和选中块几乎同色
- 优化：主按钮填充改用 `primary_fill`（深色主题里 `primary` 是文字色、偏浅，拿它当填充会发灰）
- 修复：给分组设 QSS 后子标签仍是黑字
- 修复：**次按钮上边框看起来被遮住一条** —— 顶部白色内高光是画在描边之后的，
  把上边那道 1px 边框冲淡了。改为「填充 → 内高光 → 描边」，描边按 0.5px 内缩落在像素格上
- 修复/加固：**红点按钮退出程序** —— 退出动作改为在按钮事件之外执行（`QTimer.singleShot(0, ...)`），
  避免在按钮自身事件派发中直接 `quit` 偶发不生效；退出时停掉全部定时器、线程等待加上限
  （以前 `checker.wait()` 无上限，正好撞上一次网络检测会僵住十几秒）
- 新增：**「关闭窗口即退出」开关** —— 设置里可选；关着时点 ✕ / Alt+F4 仍是收进托盘，
  开着时直接退出程序。红点=退出、黄点=收托盘，两个按钮都加了 tooltip
- 修复：**退出后进程残留** —— PySide6 在解释器收尾阶段若还有 QThread 存活会卡住不返回
  （表现：窗口没了、任务管理器里进程还在）。`main.py` 改为 `app.exec()` 返回后直接 `os._exit()`，
  不再走解释器关闭流程；该保存的配置/流量在 `quit_app` 里已经落盘
- 新增：退出/关闭路径写日志（`正在退出程序...` / `窗口关闭 → 收进系统托盘` / `进程退出，返回码 N`），
  出问题能直接从 `giwifi.log` 看出来走的是哪条分支

## 使用方法

### 基本使用
1. 双击 `dist/GiWiFi.exe` 运行
2. 输入校园网账号密码，点击"保存配置"（会自动存进账户列表）
3. 账号右侧小箭头可切换已保存的账户，密码右侧小眼睛可查看明文
4. 勾选"开机自启动"可实现开机自动运行
5. 关闭窗口会最小化到系统托盘，双击图标恢复

### 设置功能
点击标题栏右侧 ⚙ 齿轮图标，可配置：
- **启用 Windows 通知** - 登录/登出/断线时弹出系统通知（默认关闭）
- **开机静默模式** - 启动后自动最小化到托盘（默认关闭）
- **使用场景** - 自动判断 / 校园 / 家庭（家庭网络下暂停校园网登录）
- **主题模式** - 白天 / 黑夜 / 跟随系统
- **主题风格** - 经典 / 极光 / 液态玻璃（切换后重启生效）

### 其他功能
- **查看日志** - 右键托盘图标 → "查看日志"
- **手动登录/下线** - 右键托盘图标或点击主界面按钮
- **网速显示** - 主界面和托盘 tooltip 显示实时网速
